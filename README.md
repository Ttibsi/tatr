# Tatr
Task Tracker inspired by [tsoding's project of the same name](https://github.com/tsoding/tatr/)

The intention is to bundle the task tracker with the repo, so as not to tie 
the repo to a specific platform. The `tasks/` directory should be checked in 
to version control.

### Quick Start
Requirements: `python3 >= 3.12`
Dev requirements: `tox`, `pytest`

```console
$ python3 -m virtualenv venv
$ venv/bin/pip install .
```

You will likely want to install this somewhere on your path.
